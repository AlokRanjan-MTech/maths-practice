# Maths Practice

A very small beginner-friendly web app for practising multiplication tables and integer arithmetic.

## What It Does

- Choose Table Practice or Integer Practice.
- In Table Practice, choose a start table and end table from 2 to 20.
- In Integer Practice, choose addition, subtraction, multiplication, or division.
- Choose 10, 20, or 30 questions.
- Click **Start Practice**.
- Answer the random questions.
- Questions use multipliers from 2 to 10.
- See your score, timing, and review wrong answers at the end.

## Files

- `index.html` - page structure
- `style.css` - simple styling
- `script.js` - practice logic and question generators

## How To Open

Open `index.html` in your web browser.

No install, backend, database, or framework is needed.
