# Maths Table Practice

A very small beginner-friendly web app for practising multiplication tables.

## What It Does

- Choose a start table and end table from 2 to 20.
- Click **Start Practice**.
- Answer 10 random questions.
- Questions use multipliers from 2 to 10.
- See your score at the end.

## Files

- `index.html` - page structure
- `style.css` - simple styling
- `script.js` - practice logic

## How To Open

Open `index.html` in your web browser.

No install, backend, database, or framework is needed.
